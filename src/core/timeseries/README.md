# timeseries

Numerical time-series routines on plain arrays. No dates, no database: the
catalog `Series` model adapts these to its date-keyed data
(`Series.disaggregate()` / `Series.disaggregateDetailed()`).

## `disaggregate/` — `denton-chowlin`

A **deliberate partial port** of the R package
[tempdisagg](https://github.com/cynkra/tempdisagg) (temporal disaggregation
of low-frequency series to a higher frequency with an integer ratio).

**Validated against upstream commit
`5f329d0d774f4f6c725791b7cd6f90fd1d15eae9`** (tempdisagg 1.2.0,
"cran submission", 2025-11-05), R 4.5.2.

### Scope

| Supported                                                               | Not ported (throws `UnsupportedMethodError`)                                     |
| ----------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `denton`, `denton-cholette`, `uniform`                                  | `chow-lin-minrss-ecotrim`, `chow-lin-minrss-quilis` (Matlab/Ecotrim compat only) |
| `chow-lin-maxlog`, `chow-lin-fixed`                                     | `dynamic-maxlog`, `dynamic-minrss`, `dynamic-fixed` (experimental upstream)      |
| `litterman-maxlog`, `litterman-fixed`, `fernandez`, `ols`               | `litterman-minrss`, `fast`                                                       |
| conversions `sum`, `average`, `first`, `last`                           | irregular frequencies (month → day)                                              |
| Denton `h` 0–3, `criterion` `additive` / `proportional`                 | R formula interface, `ts`/`mts`, tsbox, S3 `print`/`plot`/`summary`              |
| integer ratio only (4 = annual→quarterly, 3 = quarterly→monthly, 12, …) | backcasting (`n.bc`); forecasting via a longer indicator **is** supported        |

`td.R` (the dispatcher) is not ported; the math from `td.sub.R`
(`SubDenton`, `SubRegressionBased`) and `td.calc.R` (`CalcC`, `CalcQ`,
`CalcQ_Lit`, `CalcGLS`) is, plus the numeric core of `ta()`.

### API

```ts
import { aggregate, disaggregate } from "@/core/timeseries";

const r = disaggregate(annual, {
  ratio: 4, // required, integer
  method: "chow-lin-maxlog", // default "denton-cholette"
  conversion: "sum", // "sum" | "average" | "first" | "last"
  indicator: quarterly, // number[] or number[][] (columns); optional
  intercept: true, // regression methods: R's `y ~ x` (false = `y ~ 0 + x`)
  fixedRho: 0.5,
  truncatedRho: 0,
  h: 1,
  criterion: "proportional",
  checkInvariant: true, // verify aggregate(values) ≈ input, throw otherwise
});
// r.values, r.fitted, r.residuals, r.preliminary, r.nForecast,
// regression: r.rho, r.truncated, r.coefficients, r.se, r.logl, r.aic, r.bic,
//             r.r2, r.adjR2, r.rss, r.tss, r.s2, r.s2Gls, r.rank, r.df

aggregate(r.values, { ratio: 4, conversion: "sum" }); // ≈ annual
```

`disaggregate()` defaults to `conversion: "sum"` like tempdisagg.
**`Series.disaggregate()` defaults to `"average"`** — it replaces
`interpolate(freq, "average")` and most catalog annual series are rates or
levels. In evals: `disaggregate(:quarter)`, `disaggregate(:quarter, :sum)`,
`disaggregate(:quarter, :sum, "X@HI.Q".ts)`.

Series start at the beginning of a low-frequency period. An indicator longer
than `lowFreq.length * ratio` yields that many forecast periods at the end
(`nForecast`), exactly as `td()` does in numeric mode. Without an indicator,
a constant is used (Denton without indicator; intercept-only regression).

### Numerics

Zero dependencies (`linalg.ts`, ~250 lines): Cholesky, LU with partial
pivoting, Householder QR least squares.

- Nothing is ever inverted; every `solve()` is against a right-hand side.
- GLS (`gls.ts`) whitens with the Cholesky factor of the covariance and
  solves OLS by QR. Upstream uses Paige's algorithm — same estimator,
  different rounding.
- `log|V|` for the likelihood is `2·Σ log diag(L)` from Cholesky.
- Denton's `Q = (D₀ᵀD₀)⁻¹` and Litterman's `(DᵀHᵀHD)⁻¹` are applied through
  their bidiagonal factors (cumulative sums / two-term recursions), so the
  error scales with `cond(D₀)` rather than `cond(D₀)²`. Upstream forms and
  inverts the products.
- ρ for `*-maxlog` is found by `brentFmin` (`optimize.ts`), a line-for-line
  port of R's `Brent_fmin` with R's arguments (`lower=-0.999, upper=0.999,
tol=1e-16`).

### Validation

Run: `bun test src/core/timeseries`

1. **Denton (1971) table, p. 101** (`denton-1971.test.ts`) — the eight
   `criterion × h` cases from `?td`, at 1e-10.
2. **R fixture corpus** (`r-fixtures.test.ts`, `fixtures/r-fixtures.json`,
   1,248 cases generated by `fixtures/generate-fixtures.R` at the pinned
   commit; every method × conversion × ratios 3/4 × lengths 6/12/25 ×
   intercept/no-intercept × single/double indicator with forecast tail ×
   ρ ∈ {−0.5, 0, 0.5, 0.9, 0.99} × truncatedRho ∈ {0, −1}).
   - Closed-form paths (Denton family, fixed-ρ, Fernández, OLS): **1e-10**.
   - Original `denton` with `h = 3`: **1e-6**. Upstream inverts `D₀ᵀD₀`
     (cond ≈ n⁶); we apply the factors. The two disagree at ~1e-7 and
     Denton's own objective can't separate them — both are at that
     problem's noise floor. `denton-cholette` holds 1e-10 at every `h`.
   - Litterman at |ρ| ≥ 0.99 with 100-period series: **1e-6** — upstream's
     explicit inverse has cond ≈ 1e9 there and the two disagree at ~1e-8.
   - `*-maxlog`: ρ agrees to ~1e-7, not 1e-10, and this is structural: near
     the optimum the likelihood is flat to rounding level, so any last-bit
     difference in the GLS arithmetic changes the optimiser's path. With
     `first`/`last` and ratio 4 the likelihood is an even function of ρ, so
     ±ρ are exactly tied optima and R and JS can pick opposite signs. The
     test therefore evaluates the _objective_ at both ρ's and requires the JS
     optimum to be at least as good as R's (it is in all 240 cases; strictly
     better in 3, never worse), then compares values at 1e-5 when the ρ's
     agree.
3. **Aggregation invariant** `aggregate(disaggregate(y).values) ≈ y` for every
   method × conversion, at 1e-9 (`disaggregate.test.ts`), and on every
   fixture case. It also runs at call time by default (`checkInvariant`).
