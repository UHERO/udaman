# Field: dataPortalName (the label users see)

- Must be unique within a data list, and read naturally to a portal user ("Visitor Arrivals", not "VISNS").
- Series for other geographies usually share the label exactly, so the label normally belongs on the measurement; measurements in the same data list must differ from each other.
- Seasonally adjusted and unadjusted series in one measurement may need their own labels; set those per series.
